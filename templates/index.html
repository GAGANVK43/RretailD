Hadoop MapReduce Architecture Flow
  1. Input Dataset in HDFS: Large-scale CSV/TSV retail logs stored in distributed blocks (typically 128MB each).
  2. InputFormat & RecordReader: Breaks files into lines, passing LineOffset as Key and LineText as Value.
  3. Map Phase (Mapper): Parses each transaction line, extracts Store_Location and Sales_Amount, emitting Key-Value pairs: (Store, Amount).
  4. Partitioning, Shuffle & Sort: Hadoop automatically distributes keys across reducers via hash partitioning and sorts all sales values grouped by Store.
  5. Reduce Phase (Reducer): Receives an iterator of sales for each store: (Store, [120.50, 45.00, 89.20...]), computes the total sum, and writes the result to HDFS: Store \t TotalSales.
Apache Hive Architecture & Advantage

Writing MapReduce programs in Java requires dozens of boilerplate lines for simple aggregation. Apache Hive provides:

  • Metastore: Catalogs database schemas, table locations, and columns.
  • Query Compiler & Optimizer: Automatically converts SQL-like GROUP BY queries into an optimized DAG of MapReduce or Tez jobs.
  • Schema-on-Read: Does not verify or modify data during load, allowing rapid ingest of massive unstructured/semi-structured files.
Real Hadoop Cluster Execution Commands

To run this directly on an Ubuntu/CentOS Hadoop or AWS EMR cluster:

# 1. Start Hadoop Daemons
start-dfs.sh
start-yarn.sh

# 2. Upload retail dataset to HDFS
hdfs dfs -mkdir -p /user/retail/input
hdfs dfs -put retail_transactions.csv /user/retail/input/

# 3. Execute Hadoop Streaming MapReduce
hadoop jar $HADOOP_HOME/share/hadoop/tools/lib/hadoop-streaming-*.jar \
   -files mapper.py,reducer.py \
   -mapper "python3 mapper.py" \
   -reducer "python3 reducer.py" \
   -input /user/retail/input/retail_transactions.csv \
   -output /user/retail/output_store_sales

# 4. View Results
hdfs dfs -cat /user/retail/output_store_sales/part-*

# 5. Execute via Apache Hive
hive -f hive/store_sales_analysis.hql
Common Viva / Interview Questions

Regular Python scripts run on a single machine and hit memory/CPU limits when processing multi-gigabyte or terabyte transaction datasets. MapReduce splits the computation across hundreds of commodity servers in parallel.

A Combiner (Mini-Reducer) pre-aggregates sales totals locally on each Mapper node before the network Shuffle phase, dramatically decreasing network bandwidth and disk I/O.

Hive's query planner parses SQL into an Abstract Syntax Tree (AST), optimizes the execution plan, and generates Mapper and Reducer tasks corresponding to the GROUP BY and SUM() clauses.
